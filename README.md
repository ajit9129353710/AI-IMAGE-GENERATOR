🎨 AI IMAGE GENERATOR

🚀 Turn Your Imagination Into Reality With AI

AI Image Generator is an AI-powered web application that transforms text descriptions into creative and visually appealing images.

Users can enter their imagination in the form of text prompts and generate images using Artificial Intelligence.

Imagine It. Describe It. Generate It! ✨

---

✨ Key Features

- 📝 Text-to-Image Generation – Generate images using text prompts.
- 🤖 AI-Powered Generation – Create images with AI integration.
- 🎨 Creative Image Generation – Turn ideas into visual artwork.
- ⚡ Fast Generation – Generate images through an AI-powered workflow.
- 🖼️ Image Preview – Preview generated images.
- 📥 Download Images – Download generated artwork.
- 📱 Responsive Design – Works across different screen sizes.
- 🌙 Modern UI – Clean and attractive user interface.

⚙️ Installation & Setup

1. Clone Repository

git clone https://github.com/ajit9129353710/AI-IMAGE-GENERATOR.git

2. Navigate to Project

cd AI-IMAGE-GENERATOR

3. Backend Setup

cd backend
npm install

Create a ".env" file:

PORT=5000
AI_API_KEY=your_api_key

Start Backend:

npm run dev

4. Frontend Setup

Open another terminal:

cd frontend
npm install

Create ".env":

VITE_API_URL=http://localhost:5000

Start Frontend:

npm run dev

---

🧠 How It Works

1. User enters a text prompt.
2. The application sends the prompt to the backend.
3. Backend communicates with the AI image generation service.
4. AI generates an image based on the prompt.
5. The generated image is displayed to the user.
6. User can preview and download the generated image.
